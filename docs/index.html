Fisher-matrix forecasts for galaxy clustering, weak lensing and CMB surveys, with CAMB, CLASS or a built-in symbolic backend.

Development

Features#

  • Multiple backends. Use CAMB, CLASS, the built-in symbolic backend that needs no external Einstein–Boltzmann solver, or precomputed external tables.

  • Surveys and observables. Photometric (GCph, WL) and spectroscopic (GCsp) Euclid forecasts, CMB (CMB_T, CMB_E, CMB_B) and intensity mapping (IM).

  • Finite-difference derivatives. 3PT, STEM, POLY and 4PT_FWD schemes, selected with a single option.

  • Analysis and plotting. Marginalise, reshuffle and combine Fisher matrices, and draw triangle plots to compare surveys and settings.

  • Likelihood sampling. Run Nautilus posterior sampling with the same observables and compare chains with Fisher forecasts (Likelihood sampling with Nautilus).

  • Validated. CAMB-versus-CLASS Fisher comparisons and likelihood checks are documented and reproducible from the repository scripts.
