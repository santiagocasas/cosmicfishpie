# Getting started

From a fresh environment to a Fisher matrix in three steps:

1. {doc}`installation`: install from PyPI or from source.
2. {doc}`first_forecast`: run a complete forecast in seconds, with no solver setup.
3. {doc}`overview`: what the inputs mean, and how to plot the result.

After that, the {doc}`user_guide` covers backends, observables, derivative schemes and
likelihood sampling in depth.
