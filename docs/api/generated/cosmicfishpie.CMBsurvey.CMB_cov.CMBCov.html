CMBCov#

class cosmicfishpie.CMBsurvey.CMB_cov.CMBCov(cosmopars, print_info_specs=False, *, configuration=None)[source]#

Bases: object

CMB covariance and derivatives for Fisher forecasts.

This class: - computes fiducial CMB spectra (via CMB_obs.ComputeCls) - adds instrumental noise given self.specs beam/noise settings - constructs a per-ell covariance matrix - computes numerical derivatives w.r.t. self.freeparams

Notes

The CMB implementation currently supports the observables CMB_T, CMB_E, CMB_B. Lensing spectra (e.g. phi-phi) are not implemented yet.
