# CosmicJellyfish branding

These are the assets used by the README, Sphinx documentation and project landing
page. SVG text is outlined; no installed fonts or embedded raster images are needed.
`dark` and `light` identify the intended background theme.

The complete kit (including avatars, social previews and additional PNG exports)
is archived in [cjfp-data/branding/cosmicjellyfish-logo-kit](https://dagshub.com/santiagocasas/cjfp-data/src/main/branding/cosmicjellyfish-logo-kit).
Keep these deployment copies in sync with that kit when updating the artwork.
